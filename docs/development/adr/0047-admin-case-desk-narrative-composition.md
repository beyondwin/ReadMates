# ADR-0047: 플랫폼 어드민을 케이스 데스크 + 운영 서사로 재구성

- 상태: Proposed
- 결정일: 2026-08-27
- 작성자: design/front
- 관련: ADR-0039, ADR-0040, ADR-0045, `docs/development/2026-08-27-readmates-admin-case-desk-narrative-redesign-design.md`, `front/DESIGN.md`, `front/features/platform-admin/**`

> 새 ADR은 승인됐지만 아직 미구현인 `Proposed`로 시작합니다. 코드·테스트·active architecture가 일치한 뒤에만 `Accepted`로 바꿉니다.

## 컨텍스트

어드민 10개 라우트 중 Editorial Operations Ledger 문법을 실제 구현한 화면은 Today뿐이고, Support·Audit·Analytics·클럽 상세는 공유 프리미티브 밖의 핸드롤 섬이다. 영문 eyebrow와 enum 원문이 1급 텍스트로 노출되어 멤버/호스트 화면의 paper/ink 문장형 톤과 단절되고, 같은 개념이 화면마다 다른 라벨(오늘/오늘 할 일/운영 케이스, 영수증/명령 기록/명령 접수 완료)로 불린다. 하루 운영 루프가 하나의 케이스 언어로 이어지지 않는다. 2025-2026 운영 콘솔 벤치마크(Linear Triage, Stripe Radar·Event deliveries, Sentry 조건부 스누즈, ISA-101 조용한 관측, Ghost Shade 패턴 규율, Primer 반경 비례 마찰)를 반영한 재구성이 시안 검증을 거쳐 승인되었다.

## 결정

어드민의 작업 문법을 케이스 데스크(좌 큐 + 우 증거 도켓, 도켓 내 이전/다음 순회, 이탈 4경로: 처리/보류/무시-사유 필수/병합)로, 관측 문법을 운영 서사(상주 알람 요약 바, 한 문장 서사, 정상은 숫자 숨김)로 고정한다. 내비를 오늘·클럽·파이프라인·원장 4축(+비상 레인 긴급 회수)으로 재편하고, 페이지 타입을 데스크형·원장형·서사형 3종으로 제한하며, 용어를 개념당 하나의 한국어 라벨로 통일한다. signal→case→docket→command→receipt 운영 문법과 서버 capability·safe-command 계약(ADR-0040)은 유지한다.

## 근거

- Today가 이미 큐+인스펙터로 구현되어 있어 재사용이 가장 크고, 나머지 화면을 같은 문법으로 수렴시키는 것이 학습 비용을 최소화한다.
- 1인 운영자에게 결정을 바꾸지 않는 숫자는 소음이다(ISA-101, KPI 벽 안티패턴). 정상은 조용히, 이탈만 위로.
- 무시에 사유를 강제하고 차단된 시도까지 기입하면 감사 원장이 성공만 기록하는 홍보물이 되는 것을 막는다(WorkOS 스키마 강제, ModShield).
- 페이지 타입 3종 + 역할 기반 명명(Ghost rule-of-two)이 핸드롤 드리프트의 구조적 원인을 제거한다.

## 대안

| 대안 | 기각 이유 |
|------|----------|
| 현행 유지 + 라벨만 통일 | 핸드롤 섬과 화면 간 문법 단절이 남는다. |
| B안 단독(서사 중심) | 케이스 처리 효율이 떨어지고 Today 구현 자산을 버리게 된다. |
| C안 단독(원장책) | 감사성은 최강이나 트리아지 순회가 표 문법에 눌리고, 서사 관측이 없다. |

## 결과

긍정적:
- 하루 운영 루프(트리아지→클럽→파이프라인→후속)가 한 문법으로 관통된다.
- 멤버/호스트와 같은 브랜드 톤(한국어 문장형, paper/ink)으로 정렬된다.
- 페이지 패턴 3종 제한으로 시각 계약·CT 잠금 표면이 줄어든다.

부정적/감수한 비용:
- Support·Audit·Analytics·클럽 상세의 전면 재조립 비용과 CT 재잠금.
- 조건부 스누즈(신호 재발 시 자동 복귀)는 서버 판정이 없으면 1단계에서 시각 기반으로 축소된다.
- ADR-0039의 내비 축(오늘·클럽·서비스·검토) 서술과 ADR-0045의 admin composition이 수정 대상이 된다.
